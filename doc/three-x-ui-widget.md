# Виджет 3x-ui

Конфигуратор добавляет специализированный тип `3x-ui`, который сохраняется в
`services.yaml` как стандартный виджет Homepage `customapi`.

Один локальный API-запрос объединяет данные из следующих read-only методов
панели:

- `GET /panel/api/server/status`;
- `POST /panel/api/clients/onlines`;
- `GET /panel/api/inbounds/list/slim`;
- `GET /panel/api/server/getPanelUpdateInfo`.

## Настройка

1. В 3x-ui откройте `Settings → API Tokens` и создайте отдельный токен.
2. В редакторе карточки выберите тип виджета `3x-ui`.
3. Укажите имя подключения, URL панели вместе со скрытым web base path и токен.
4. Нажмите `Проверить и сохранить`.
5. Отметьте галочками данные, которые должны отображаться.

По умолчанию включены TCP, UDP, число клиентов онлайн и суммарный отправленный
и полученный сетевой трафик.

В компактном списке доступны только основные показатели: TCP, UDP, клиенты
онлайн, отправленный и полученный трафик, загрузка CPU, занятость RAM,
состояние Xray, версия панели и наличие обновления 3x-ui.

Подключения хранятся в `/opt/homepage/config/three-x-ui.yaml` с правами `0600`.
API-токен не записывается в `services.yaml` и не возвращается интерфейсу.
Сформированный виджет обращается только к локальному API:

```yaml
widget:
  type: customapi
  url: http://127.0.0.1:3000/api/config/three-x-ui?source=main
  refreshInterval: 30000
  mappings:
    - field: tcp
      label: TCP-соединения
      format: number
```

Сводка кешируется на 15 секунд, а проверка новой версии панели — на 6 часов.
Endpoint не запускает обновление, перезапуск или другие изменяющие состояние
операции 3x-ui.
