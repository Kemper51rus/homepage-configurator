# Перенос карточек между сервисами и закладками

Только **Homepage Configurator / Classic**. Homepage Studio в этой доработке не меняется.

Включите `Редактировать` и перетащите карточку:

- на карточку другого типа — вставить перед ней;
- в область добавления целевой группы — добавить в конец, в том числе в пустую группу.

## Какие данные сохраняются

Общие поля: `id`, `href`, `icon`, `description`, `abbr`, `target`, `titleColor`, `titleSize`, `titleAlign`, `titleFont`. Имя карточки сохраняется.

При переносе сервиса в закладки **удаляются** настройки, не поддерживаемые закладками: виджеты, Docker/container, Proxmox, ping/siteMonitor, статистика, weight и прочие дополнительные service-only поля. Обратный перенос не восстанавливает удалённые данные.

При переносе закладки в сервис не переносится bookmark-only `showLink`. Порядок сервисов в целевой группе нормализуется по весам, чтобы карточка появилась в позиции drop.

## Сохранение

Источник и назначение разрешаются сервером из актуальных YAML по идентификаторам карточек. Браузер не передаёт готовый config карточки, файловые пути или команды. Несуществующие/устаревшие/неоднозначные карточки и группы не удаляются.

Перенос между двумя файлами сериализуется с обычными записями конфигурации. Сначала публикуется назначение, затем удаляется источник; при ошибке записи выполняется rollback под теми же блокировками. Это не единая атомарная filesystem-транзакция: при аварийной остановке между двумя публикациями возможен дубликат, но карточка не должна исчезнуть из обоих файлов.

Автоматическое скачивание новой иконки при переносе не запускается. Существующая иконка сохраняется; CSS вне сгенерированного блока заголовков не меняется.
