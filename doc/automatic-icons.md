# Иконка при первом сохранении карточки

При первом сохранении нового сервиса или закладки редактор пытается найти favicon сайта, если `icon` пуст и задан HTTP(S) `href`. Явно выбранная иконка не заменяется. Сохранение существующей карточки не запускает этот поиск, поэтому удалённая пользователем иконка не появляется повторно.

Это best-effort операция: недоступный сайт, отсутствие favicon или ошибка загрузки не блокируют сохранение. Общее ожидание ограничено; фоновый поиск после сохранения не запускается. Найденная иконка сохраняется локально и отдаётся через `/api/config/icon/<file>`.

## Внутренние сайты

Произвольный доступ к внутренней сети не разрешается. Для собственных LAN/CGNAT сервисов администратор может задать в окружении Homepage:

```dotenv
HOMEPAGE_ICON_DISCOVERY_ALLOWED_ORIGINS='["http://192.168.1.20:8080","http://100.100.0.187:8787"]'
```

Список задаётся только на сервере и содержит точные HTTP(S) origins с literal private IPv4; схема и порт учитываются. Loopback, link-local, cloud metadata и credentials в URL не разрешаются. Политика обычного ручного скачивания иконок не расширяется. Добавление нового внутреннего хоста в этот список — действие администратора, не параметр браузерного запроса.

При автоматическом поиске DNS-адреса публичных hostname проверяются до соединения, а выбранный IP закрепляется для HTTP(S)-запроса. DNS rebinding и перенаправление на неразрешённую внутреннюю сеть не открывают доступ к ней.

Приложение и editor API должны публиковаться за Authentik или другим внешним authentication proxy. Если сайт перенаправляет на другой hostname (например, страницу входа Authentik), её favicon не подставляется вместо иконки проекта.

## Проверка

```bash
npm run check
HOMEPAGE_BROWSER_SMOKE_URL=http://<dashboard>:3000/ \
HOMEPAGE_ICON_SMOKE_SITE_URL=https://<site-with-favicon>/ \
node scripts/icon-discovery-smoke.mjs
```

Browser smoke временно создаёт сервис и закладки, проверяет реальный первый save, отсутствие повторного поиска при edit и сохранение при ошибке поиска. В `finally` удаляет только свои уникальные тестовые записи из свежепрочитанного конфига.

## Существующие карточки

Массовой перезаписи иконок нет. Для существующих карточек иконку можно выбрать/загрузить вручную. Сайт без favicon не получает случайную или выдуманную иконку.
