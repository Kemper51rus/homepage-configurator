# Сохранность custom.css при записи конфигурации

## Симптом

Флаг IP и PNG-кнопки радио внезапно отображаются в натуральном размере, блоки теряют flex-разметку. Это не ошибка определения IP: проверьте содержимое `/api/config/custom.css`. Если осталось только несколько строк `HOMEPAGE-CONFIGURATOR TITLE STYLES`, остальные пользовательские и managed-стили потеряны.

## Исправленный механизм потери данных

Раньше raw/config writers и `updateCustomCssWithStyles` использовали `fs.writeFile` непосредственно на live-файле. Между открытием с truncate и завершением записи другой read/modify/write мог прочитать пустой CSS и сохранить только сгенерированный title block. Аналогичное окно существовало у installer `cp -f` при обновлении managed-фрагментов. Детерминированный regression test воспроизводит такое interleaving; forensic trace конкретного потерявшего CSS runtime-запроса не был записан.

Теперь конфигурация записывается во временный файл в той же директории и публикуется атомарно. CSS read/modify/write и raw writes сериализуются по каноническому пути в процессе; сохраняются права файла и существующий symlink на config-файл. Создание отсутствующего текстового конфига не перезаписывает файл, появившийся параллельно. Installer custom CSS/JS mutations также публикуют целиком готовый файл, без предварительного обнуления live target.

## Восстановление и проверка

На runtime полный CSS восстановлен из резервной копии, включая пользовательские стили и managed `cards`, `extras`, `radio`, `particles`. JavaScript, YAML и картинки сохраняются.

```bash
npm run check
HOMEPAGE_BROWSER_SMOKE_URL=http://<runtime>:3000/ node scripts/topbar-layout-smoke.mjs
```

`topbar-layout-smoke.mjs` проверяет компактные размеры IP/радио на трёх ширинах окна. `icon-discovery-smoke.mjs` теперь дополнительно сравнивает CSS вне auto title block до и после всех сохранений карточек.

Файл, явно полностью заменённый пользователем через редактор CSS, всё ещё заменяется согласно этому действию. Атомарная запись предотвращает пустые/частичные промежуточные состояния, а не запрещает редактирование.
